> Documentation complète : voir le [README à la racine du dépôt](../README.md).

## Démarrage rapide

### Backend (port 3001)

```bash
cd rtc-backend
npm install
npm run setup
npm run dev
```

### Frontend web (port 3000)

```bash
cd rtc-frontend
npm install
npm run dev
```

### Desktop (Electron)

```bash
cd rtc-desktop
npm install
bash start-dev.sh    # lance backend + frontend + Electron
```

### Tests

```bash
cd rtc-backend
npm test
```
